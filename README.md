# 国考选岗助手

一个单文件网页工具 + 一个报告生成脚本，从国考职位表里筛出能报、值得报的岗位，并生成个性化选岗报告。

当前版本：**`国考选岗助手-2027.html`（19,426 个岗位）**。仓库只保留最新年度版本，跨年对比需自行留存上一年度的 HTML。

> 纯前端单文件、完全离线、零外部依赖：职位数据、专业对照表、Excel 解析库全部内嵌在一个 HTML 里，双击即用，不需要联网、不需要安装。

## 最快上手

1. 双击 `国考选岗助手-2027.html`
2. 左侧填考生条件 → 右侧按偏好筛 → 点开岗位逐个打分
   - **专业填毕业证上的全称**（如「汉语言文学」），别填「文学」这种学科门类 —— 填门类会漏掉大批本可报的岗位
   - **考生身份要分清**：岗位写「限2027届高校毕业生」＝只有当年毕业的能报；写「应届高校毕业生」＝两年择业期内未落实工作单位的也能报。填错这一项，结果会差好几倍
   - **性别**：不少岗位在备注里限男/限女，填了会自动筛掉不符合的
3. 点右上角「**导出配置**」，存成 `xxx-选岗配置-日期.json`
4. 生成报告：
   ```
   python 生成选岗报告.py xxx-选岗配置-日期.json
   ```
   报告输出到 `选岗报告/` 目录

> **第三步（逐岗打分）不能省。** 不做的话，报告里的排序就是机器默认值，工具会在报告里明确提醒。

## 换新一年的数据

两种方式，推荐第一种：

**A. 直接导出新版本文件（已内置数据，双击即用）** —— 2027 版就是这么做的。见 `国考选岗助手-2027更新说明.md`。

**B. 用工具的「导入新表」按钮** —— 打开工具，点顶部「导入新表」，选新一年的国考 Excel。
不落盘，每次打开都要重新导入一次；适合临时试算。
（若要更新内置的专业对照表，才需要动 `工具源文件/`，见技术档案第八章。）

## 环境要求

- 工具：Chrome 80+ / Edge 80+ / Firefox 113+（需要 `DecompressionStream`），无需联网
- 生成脚本：Python 3 + `playwright`，且需 `playwright install chromium`
